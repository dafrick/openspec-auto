Known Limitations

quick_validate CI
No false positives observed. Pinned to commit 5754626 for reproducibility — no stable release tag is published upstream.
skill-lint local
TOXIC verdict on any skill with TypeScript files
Rule R06 scores every .ts file as a suspicious bundled executable regardless of content. 17 scripts → score 17 → verdict TOXIC. No allowlist or per-file exception exists; --help exposes only --json, --install, --force-install. Rules R01–R05 and R07–R10 found nothing in actual content — the verdict is entirely from the file-type heuristic. Disabled in CI; kept in Justfile for local use.
agent-skills-lint CI
Treats every .md file as a skill file
Prompt templates in prompts/*.md had no name: frontmatter → 6 false-positive errors. Fixed by adding YAML frontmatter to all prompt files.
allowed-tools not in its schema
Emits unknown-frontmatter-key on every skill that declares tool restrictions. The field is intentional and valid per the Claude skill spec — this is a false positive.
skill-check removed
Security scan built for MCP servers, not skills
Delegates to mcp-scan (now snyk-agent-scan — a Snyk product for claude_desktop_config.json). Against a skill directory it returns target=(unknown target) with 0 findings yet exits 1 with security: FAIL. Category mismatch, not a real finding. Replaced by gitleaks for secrets scanning.
pulser CI
Brittle section name matching
Checks headings by exact string — requires ## Gotchas, not ## Red Flags with identical content. The only fix is renaming sections.
Wrong allowed-tools auto-fix for orchestrators
Auto-suggests Read, Grep, Glob for any skill classified as generation (confidence 0.5). For orchestrators that need Bash, Agent, Skill, EnterWorktree, ScheduleWakeup, this would break the skill. Derive tool lists from the skill's actual stage-by-stage behaviour.
cclint CI
No false positives observed. Score of 38/100 (grade D) reflects real documentation gaps — findings are at SUGGESTION level and actionable. Four-dimension breakdown (Structural / Practices / Composition / Documentation) is uniquely useful for Claude Code–specific conventions.
agnix CI
Scans node_modules/ without exclusion
All 9 hardcoded-path warnings and the 8 MB size error came from @types/node / typescript packages, not project code. CI passes because node_modules/ is not installed in the runner; local runs are noisy.
Flags prescriptive install paths as portability warnings
Paths like ~/.agents/skills/openspec-auto inside intentionally prescriptive bash code blocks are flagged. The underlying concern is real (tracked in a GitHub issue); warnings are expected until resolved at the script level.
skillscan-lint CI
QL-002 sentence-length rule (max 30 words) miscalibrated for skill docs
Tables, code blocks, and Mermaid diagrams are parsed as prose sentences — 18 of 18 QL-002 warnings were false positives (a table row counted as 268 words; a Mermaid diagram as a single run-on sentence). The 30-word cap targets marketing prose, not structured specification writing. Prose-quality rules that fire on actual text — superlatives, weasel words, acronyms — are real and actionable.
